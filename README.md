# Проект интернет-магазина

## Описание проекта

Проект представляет собой модель данных интернет-магазина, реализованную на Python.

### Реализованный функционал

- **Класс `Product`** - хранит информацию о товаре: название, описание, цену и количество на складе.
- **Класс `Category`** - хранит название категории, её описание и список входящих в неё товаров.
- **Класс `Smartphone`** — наследуется от Product и содержит дополнительные характеристики: производительность, модель, объём встроенной памяти и цвет.
- **Класс `LawnGrass`** — наследуется от Product и содержит дополнительные характеристики: страна производства, период прорастания и цвет.
- **Подсчёт категорий** - автоматически увеличивает счётчик при создании нового объекта `Category`.
- **Подсчёт товаров** - учитывает количество товаров, переданных при создании категории.
- **Сложение товаров** — реализована возможность складывать стоимость товаров с учётом их количества. Сложение разрешено только для объектов одного класса.
- **Добавление товаров в категорию** — метод add_product() позволяет добавлять объекты класса Product и его наследников. При попытке добавить объект другого типа возникает исключение TypeError.
- **Типизация** - использованы аннотации типов для атрибутов и параметров конструкторов классов.
- Создан **абстрактный класс** `BaseProduct` для общей структуры товаров.
- Добавлен класс `PrintMixin`, который выводит информацию о создании объекта и переданных аргументах.

### Тестирование


Для проверки корректности работы проекта используются тесты `pytest`.

Тесты проверяют:
- Инициализацию классов `Product` и `Category`.
- Корректность работы счётчиков категорий и товаров.
- Инициализацию классов `Smartphone` и `LawnGrass`.
- Сложение товаров одного класса.
- Обработку ошибки при сложении товаров разных классов.
- Добавление товаров в категории.
- Обработку ошибки при добавлении объекта, не являющегося продуктом.

### Покрытие тестами
